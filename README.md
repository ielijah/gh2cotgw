# Русификации игр KOEI о Чингисхане

Репозиторий объединяет два самостоятельных проекта.

| Проект | Платформа | Состояние |
| --- | --- | --- |
| [Genghis Khan II: Clan of the Gray Wolf](projects/mega-drive/README.md) | Sega Mega Drive / Genesis | Релиз русификации 1.0.0 |
| [Aoki Ookami to Shiroki Mejika — Genchou Hishi](projects/sega-cd/README.md) | SEGA CD / Mega-CD | Подготовлена папка нового проекта |

Все материалы завершённой работы находятся в `projects/mega-drive/`: инструменты, переводы, графика, результаты анализа и документация. Команды из инструкции этого проекта выполняются из его папки.

Новый проект русификации дисковой версии размещается отдельно в `projects/sega-cd/`.

ROM, образы дисков, звуковые дорожки, локальные сборки и релизные пакеты не публикуются. Каждый проект использует собственные локальные исходники и результаты сборки. Переводы распространяются в виде патчей и инструментов.

При работе над переводом Mega Drive использовались наработки участников [форума Chief-Net](http://chief-net.ru/forum/topic.php?forum=4&topic=35&p=1). Подробности и благодарности приведены в документации проекта.
