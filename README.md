# Genghis Khan II — русский перевод

Здесь лежит перевод игры «Genghis Khan II: Clan of the Gray Wolf» — «Чингисхан II: Клан серого волка».

Есть две версии игры. Выберите свою:

| Версия | Что готово |
| --- | --- |
| **Sega Mega Drive / Genesis** — игра на картридже | Выпущен перевод 1.0.0. Основные кампании пройдены. [Подробнее о переводе](mega-drive/README.md). |
| **Sega CD / Mega-CD** — игра на компакт-диске | Перевод ещё в работе. Есть русский текст и озвучка, но местами остаётся японский. |

## Хочу запустить Sega CD

**Самой игры — файла ISO — здесь нет.** Одного скачанного архива недостаточно для запуска. Нужен переведённый ISO, подготовленный отдельно. Простое переименование японского ISO не переведёт текст игры.

Если переведённый ISO у вас уже есть:

1. На главной странице этого репозитория нажмите зелёную кнопку **Code**, затем **Download ZIP**.
2. Распакуйте скачанный архив. Запускать игру прямо из архива не нужно.
3. Откройте папку **sega-cd**, а в ней — **dub**. Там находятся `game.cue` и все 89 звуковых дорожек. Аудиофайлы занимают около 568 МБ.
4. Скопируйте свой переведённый ISO в эту же папку и назовите его **track01.iso**. Если расширения файлов скрыты, включите их отображение в Проводнике, чтобы случайно не получить имя `track01.iso.iso`.
5. В эмуляторе откройте **game.cue**.

Всё должно лежать рядом:

```text
sega-cd/dub/
    game.cue
    track01.iso       ← этот файл нужно добавить самостоятельно
    track02.wav
    track03.wav
    ...
    track90.wav
```

**CUE — это список файлов диска.** Он сообщает эмулятору, где находятся игра и звук. Поэтому для запуска выбирайте `game.cue`: при открытии одного ISO музыка и озвучка могут отсутствовать.

Перевод проверяется в **Genesis Plus GX**. Если вы пользуетесь RetroArch, выберите это ядро. Для японской версии Sega CD ему также нужен японский BIOS под именем `bios_CD_J.bin` в папке `system` RetroArch. BIOS в этом репозитории нет.

[Открыть папку с аудиодорожками и CUE](sega-cd/dub)

## Что переведено в Sega CD

- Все 453 описания биографий.
- Многие имена, меню и игровые реплики. Всего в текущей сборке 2839 переведённых текстовых полей.
- Озвучка дорожек 02–79 и диктор во вступлении, дорожка 90.

Дорожки 80–89 оставлены в оригинале и тоже лежат в папке `dub`. Перевод Sega CD пока не завершён: японские надписи и отдельные имена ещё встречаются.

## Если что-то не работает

**Игра не запускается.** Проверьте, что добавили `track01.iso`, распаковали архив и открываете `game.cue`. В RetroArch также проверьте выбранное ядро и наличие BIOS.

**Нет музыки или голосов.** Откройте `game.cue`, а не ISO. Все WAV-файлы должны находиться рядом с ним. Не переименовывайте их.

**После обновления вместо текста непонятные символы.** Запустите обновлённую игру с начала, без старого быстрого сохранения эмулятора — Save State. Такое сохранение хранит в том числе старые данные шрифта и может не подходить к новой сборке.

**Попалась опечатка или текст вышел за рамку.** Пришлите снимок экрана и коротко напишите, как до него дойти. Укажите версию игры: Mega Drive или Sega CD. Записывать видео всего прохождения не нужно.

## Если хотите собрать перевод самостоятельно

Ниже — материалы для тех, кто работает с переводом. Для запуска уже подготовленного ISO этот раздел можно пропустить.

- [Mega Drive: описание и инструменты](mega-drive/README.md).
- [Sega CD: ход работы и технические подробности](sega-cd/README.md).
- В папках `translation` лежат переводы, в `tools` — программы сборки и проверки, в `assets` — шрифты и графика, в `analysis` — отчёты.

Исходные игры, BIOS и готовые ISO не публикуются. Для сборки нужны свои исходные файлы игр и настроенный Python. Скрытая папка `.runtime`, упоминаемая в технических инструкциях, — локальное окружение разработчика; при скачивании с GitHub её не будет.
