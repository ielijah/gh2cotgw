# Глоссарий и редакционные решения

Версия 0.3. Основа — обсуждение [Genghis Khan II на Chief-Net](http://chief-net.ru/forum/topic.php?forum=4&topic=35). Сохранены локальные снимки семи страниц для проверки контекста. Предложения участников, позднейшие поправки и окончательные договорённости различаются: первый список в теме не считается безошибочным словарём.

## Игровые термины

| Оригинал | Принятый вариант | Основание |
|---|---|---|
| Soldier | солдат | Нижний уровень игровой иерархии |
| Unit | юнит | Итог обсуждения 25–27 марта 2016, [страница 5](http://chief-net.ru/forum/topic.php?forum=4&topic=35&p=5) |
| Legion | легион | То же обсуждение; исправлено прежнее «корпус» |
| Army | армия | То же обсуждение |
| General | генерал в коротких подписях; полководец в описаниях | Редакционное решение для общего интерфейса разных держав; прежнее «воевода» убрано из коротких подписей |
| Lord | лорд | Общее игровое обращение; не заменяется повсеместно титулом «хан» |
| Governor | наместник | Управление зависимой областью |
| Advisor | советник | Функция персонажа |
| Rate | Цена | Прямое указание пользователя; индикатор «Цена:1.0» |
| A–E | A–E | Латинские оценки оставлены, согласно обсуждению 24–25 марта 2016 |

«Юнит — легион — армия» — единая игровая терминология для всех народов, а не утверждение об исторической структуре каждой армии. Предложение называть все соединения тумэнами не было принято участниками после обсуждения европейских, китайских и арабских государств.

## Сценарии

| Оригинал | Полное название |

| Mongol Conquest | Завоевание Монголии |
| Genghis Khan | Чингисхан |
| Yuan Dynasty | Династия Юань |
| World Conquest | Завоевание мира |

Основание: [начало темы](http://chief-net.ru/forum/topic.php?forum=4&topic=35&p=1), с обычным регистром нарицательных слов. Чтобы сохранить смысл первого сценария, вариант «Поход монголов» заменён полным названием. Три строки перенесены по указателям; окно выбора расширено. Исправлен размер стека в процедуре выделения: исходного буфера на 16 колонок недостаточно для 18 колонок перевода.

В текущем формате имя персонажа занимает 12 байт вместе с завершением; безопасная русская подпись ограничена 11 буквами. Для длинных имён используются перечисленные краткие формы, а не склейки слов или имена других людей. Расширение всех полей персонажей ещё не сделано.

## Названия держав и спорные варианты

- Chin — «Династия Цзинь», без подмены Цзинь на Цинь. Обсуждение: [страница 2](http://chief-net.ru/forum/topic.php?forum=4&topic=35&p=2).
- Rum Seljuks — «Румский султанат». Предложение о каганате было впоследствии исправлено в самой теме.
- Angevin Kingdom — «Анжуйская держава», редакционное уточнение вместо прежнего «Анжуйское королевство». Территории анжуйских правителей по обе стороны Ла-Манша описаны на [официальном сайте британской монархии](https://www.royal.uk/angevins).
- Koryo — «Корё». Ранний вариант форума «Когурё» не перенесён: для периода игры требуется Корё. Различие государств отражено в [истории Кореи Национального института корейской истории](https://contents.history.go.kr/resources/common/pdf/A%20History%20of%20Korea_The%20Understanding%20Korea%20Series.pdf) и [Национальном атласе Республики Корея](https://nationalatlas.ngii.go.kr/pages/page_1267.php).

Остальные имена и термины ещё требуют редакторской сверки. Наличие источника в форумной переписке само по себе не превращает спорную гипотезу в установленную идентификацию.


## Карта, версия 0.3.3

Названия областей хранятся отдельными полями по 15 байт, включая нулевое завершение. Переведены все 33 подписи мировой карты; Russia передано как «Русь» для исторического периода игры. Короткие формы «Внутр.Монголия» и «Берег Балтики» обусловлены полем длиной 14 букв.

Kao-Chang передано как «Гаочан» вместо раннего форумного «Као-Чень»: соответствие исторических написаний Kao-ch’ang / Gaochang рассмотрено в исследовании [Zhang & Rong, Turfan and Its Exploration](https://www11.ihp.sinica.edu.tw/storage/w2_file/1526HBCGUNx.pdf). Названия в этой таблице относятся к географическим областям, а не к названиям династий.

Неоднозначные Bogodo, Barguchin, Gorgonak, Toula и Kassagol пока не заменены: требуется уточнить идентификацию и выбранную транскрипцию.


## Дополнения 0.4

- Taitu → Тайчу, Dai Doguru → Дайдахур: приняты поздние варианты из обсуждения на странице 3 Chief-Net. Ohime → Охимэ, Sanmanhime → Санманхимэ: транскрипция игровых имён без спорного отождествления с другими женщинами.
- Для редких Yufnan, Fubarift, Godanisqieu, Vanquvan, Choswa, Halikhan, Tarrube и подобных принята транскрипция английской формы. Это рабочие формы, а не подтверждённая идентификация исторического лица; дальнейшая редактура допустима.
- Краткие формы в ограниченном поле: Ilk Sangun → Ильха (Ильха-Сэнгун), Signak Tegin → Сигнак, Nalpatya → Нарапати; титулы не заменяют имя другого персонажа. Для других ранее сокращённых имён сохраняются решения из таблицы выше.
- Династические номера теперь обычные ASCII I, II, III, IV, V, VIII, X. В английском ROM использованы специальные глифы: $, обратная косая черта, ^, }~, @, {|, =. Для Alfonso выбрана допустимая форма Альфонс, чтобы сохранить номер VIII в поле.
- Оставшиеся названия монгольской карты: Горы Богдо, Горы Баргучин, Река Горгонак, Река Туул, Озеро Косогол. Для первых трёх использованы формы из форумного глоссария без неподтверждённой привязки к современным объектам. Косогол — историческое название; написания Kossogol / Kassagol рассмотрены в статье [«Байкал: миф и образ»](https://projectbaikal.com/index.php/pb/ru/article/download/573/1946/2580).
- Префикс генератора Abdel передан «Абдел » без мягкого знака, чтобы комбинации с шестибуквенным вторым компонентом сохраняли исходный предел 12 символов. Реальные исторические имена в таблице people переводятся отдельно.
