# CD-аудио и гарем: проверка 2026-11-09

Исправлена упаковка CUE, код игровой логики не изменён. Старые относительные FILE последовательно меняли базовый каталог в Genesis Plus GX. В новой упаковке все 90 коротких имён находятся в одной папке.

Проверки:
- `verify.py`: ISO/IPS, разрешённые диапазоны патча, 70 графических элементов, оригинальные файлы и оба комплекта по 90 дорожек.
- `test_interface.py`: одинаковый экран подтверждения в оригинале и переводе; изменение выбора и возврат, без повреждения остальных пикселей.
- `test_harem.py`: 44 600 кадров с холодного запуска, новая кампания, выбор супруги, приветствие, ответ, выход на карту. Итоговый кадр визуально проверен и закреплён SHA-256.
- Воспроизведение старой ошибки: одинаковая последовательность из состояния карты со старым и новым CUE. `broken-regression.png` — реплика остановилась, `fixed-regression.png` — доступно меню.
- При отключённых FM/PSG/PCM сигнал русской CD-речи имеет пик 14270, со старым CUE — 0. CD-аудио вступления имеет пик 24911. Отчёты `cdda-test.json`, `harem-regression.json`.
- На проверенном участке карты CD-канал молчит также в неизменённой японской версии. Синтезаторная музыка карты является штатной, а не следствием потери WAV.

Русские WAV 02–79 сохранены побайтно; дорожки 80–90 совпадают с оригиналом. Полное прохождение всех сценариев и всех ветвей гарема не выполнялось.

В тестовом libretro-хосте исправлен ответ GET_VARIABLE: для отсутствующего параметра value обнуляется; ранее предыдущая строка могла ошибочно восприниматься как значение другой настройки. Добавлены запись аудио и тестовые состояния. Пользовательские настройки RetroArch не изменялись.
