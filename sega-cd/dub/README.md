# Звук и файл запуска Sega CD

В этой папке лежат **все 89 аудиодорожек** и **game.cue**. CUE уже настроен на файлы в этой же папке. Менять в нём ничего не нужно.

## Как запустить

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Добавьте в эту папку переведённый образ игры под именем **track01.iso**. ISO в скачанном архиве нет.
3. Откройте **game.cue** в эмуляторе Sega CD.

Все файлы должны лежать рядом:

```text
game.cue
track01.iso       ← добавьте самостоятельно
track02.wav
track03.wav
...
track90.wav
```

**Без ISO игра не запустится.** Японский образ, просто переименованный в `track01.iso`, не станет русским. Если вы собирали перевод нашими инструментами, нужный файл называется `build/genchou-hishi-ru-experimental.iso`: скопируйте его сюда и переименуйте в `track01.iso`.

Открывайте именно **game.cue**, а не ISO. Так эмулятор найдёт и игру, и все звуковые дорожки. WAV-файлы не переименовывайте и не переносите по отдельности.

## Что здесь звучит по-русски

- Дорожки **02–79** — переведённые реплики.
- Дорожка **90** — вступление с русским диктором.
- Дорожки **80–89** — оригинальный звук.

Общий размер аудиофайлов — около 568 МБ. Они взяты из проверенной сборки без изменения качества.

## Для тех, кто собирает перевод

Формат WAV: stereo PCM 16-bit, 44100 Hz. Границы CD-секторов сохранены. Контрольные суммы файлов находятся в `tracks.json`.

Сборщик ожидает русские дорожки в `sega-cd/build/audio-ru/` под именами `track02-ru.wav` … `track79-ru.wav` и `track90-ru.wav`. Для повторной сборки скопируйте туда соответствующие WAV из этой папки, добавив `-ru` к именам. Оригинальные дорожки для сборки берутся из вашего исходного диска.
