# Аудиодорожки Sega CD и CUE

Все 89 аудиодорожек и `game.cue` находятся в одной папке. Дорожки 02–79 и 90 переведены; 80–89 сохранены в оригинале. CUE ссылается на соседние файлы без вложенных путей. WAV скопированы из проверенного комплекта playable-dub без перекодирования: stereo PCM 16-bit, 44100 Hz, границы CD-секторов сохранены. Контрольные суммы — в `tracks.json`.

ISO намеренно не опубликован. Для запуска добавьте в эту же папку самостоятельно собранный `build/genchou-hishi-ru-experimental.iso` под именем `track01.iso`, затем откройте `game.cue` в эмуляторе. До добавления ISO комплект не запускается.

Для повторной сборки русские WAV можно скопировать в `sega-cd/build/audio-ru/` под именами `track02-ru.wav` … `track79-ru.wav`, `track90-ru.wav`, которые ожидает сборщик.
