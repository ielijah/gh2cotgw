# Genghis Khan II — русский перевод для Mega Drive

«Чингисхан II: Клан серого волка» на русском языке для **Sega Mega Drive / Genesis**. Это версия игры на картридже.

**Релиз 1.0.0 — 8 ноября 2026 года.** Основные кампании за монголов и за Чингисхана пройдены тестировщиком. Остальные сценарии и все редкие события полным прохождением не проверены.

Нужна версия для **Sega CD**? [Перейдите к общей инструкции](../README.md). Звуковые дорожки и CUE для Mega Drive не нужны.

## Что здесь можно скачать

В этой папке находятся материалы перевода и программы для его сборки.

**Готового файла игры и IPS-патча в этой папке нет.** Кнопка **Code → Download ZIP** скачивает исходные материалы, а не готовую игру. Папки `build` и `release`, упомянутые в технических записях, на GitHub не загружены.

ROM — это файл с содержимым игрового картриджа. IPS-патч — небольшой файл с изменениями: он добавляет перевод к подходящему оригинальному ROM.

## Как запустить, если перевод у вас уже есть

### Есть готовый русский файл игры

Распакуйте архив, если файл лежит в архиве. Откройте русский ROM в эмуляторе Mega Drive / Genesis. Файл может иметь расширение `.gen`, `.bin` или `.md`.

ISO, CUE и отдельные звуковые дорожки для этой версии не нужны.

### Есть только IPS-патч

1. Подготовьте чистый американский ROM **Genghis Khan II: Clan of the Gray Wolf (USA)**. Сохраните отдельную копию оригинала.
2. В программе для применения IPS-патчей выберите файл перевода `.ips` и чистый оригинальный ROM.
3. Сохраните результат отдельным файлом и откройте его в эмуляторе Mega Drive / Genesis.

Патч рассчитан на конкретный американский оригинал. Не накладывайте его на японскую версию, другую русификацию или уже изменённую игру. Если программа сообщает, что исходный файл не подходит, проверьте ROM.

## Что переведено

- Диалоги, меню, подсказки и игровые события.
- Боевые команды, дипломатия и управление землями.
- Имена персонажей и названия государств.
- Вступительные надписи, название игры и финальная надпись «КОНЕЦ».
- Экранная клавиатура для ввода русских имён.

В релизе 1793 текстовые замены. Это число записей, включая повторы, а не процент готовности.

Кириллический шрифт сделан с сохранением характера оригинала. Исправлены замеченные проблемы с цветом букв, пробелами, окончаниями слов и текстом, выходившим за рамки. Опечатки и недочёты на редких экранах ещё возможны.

## Если что-то не работает

**Игра не запускается после применения патча.** Проверьте, что патч применён один раз к чистой американской версии. Попробуйте заново сделать копию оригинала и повторить применение.

**После обновления появился испорченный текст или странное поведение.** Проверьте запуск с начала, без старого быстрого сохранения эмулятора — Save State. Оно хранит состояние предыдущей сборки и может не подходить к новой. Перед заменой файлов сохраните копию своих сохранений.

**Нашли ошибку в переводе.** Пришлите снимок экрана, название сценария и действие, после которого появилась ошибка. Укажите версию перевода и название эмулятора. Короткого описания достаточно.

## Для тех, кто хочет собрать перевод

Если у вас уже есть русский ROM или готовый патч, этот раздел можно пропустить.

Нужны Python, чистый американский ROM и ROM той версии перевода, из которой взяты шрифты. Эти файлы игр в репозитории не опубликованы. Сборщик проверяет их контрольные суммы: произвольные похожие версии не подойдут.

Разложите исходные файлы так:

```text
mega-drive/
    rom/
        original.gen       ← чистый американский ROM
        reference/
            reference.md   ← ROM — источник шрифтов
    tools/
    translation/
    assets/
```

Откройте PowerShell в папке `mega-drive` и выполните:

```powershell
python tools/build.py
python tools/verify.py
```

Эти две программы используют стандартную библиотеку Python. После успешной сборки появится папка `build`:

- `genghis2-ru-experimental.gen` — русский ROM;
- `genghis2-ru-experimental.ips` — патч для чистого оригинала;
- `manifest.json` — сведения о сборке и контрольные суммы.

Слово `experimental` в именах файлов сохранено в инструментах. Номер версии записан в `manifest.json`.

Папка `.runtime` в старых технических записях — локальное окружение разработчика. Она не скачивается вместе с репозиторием.
