# Aoki Ookami to Shiroki Mejika — Genchou Hishi

Проект русификации версии для **SEGA CD / Mega-CD**, KOEI, 1993, японский регион NTSC-J.

Исходный набор, указанный пользователем: `Aoki Ookami to Shiroki Mejika - Genchou Hishi (1993)(KOEI)(NTSC)(JP)(Track 01 of 90)[!]`.

Статус: подготовлена структура проекта. Анализ диска, извлечение текста и создание перевода ещё не выполнены. Название исходного файла не подтверждает формат образа и структуру дорожек: это предстоит проверить по исходному набору и его CUE.

## Структура

- `disc/` — локальные образы, CUE и дорожки; исключены из Git.
- `analysis/` — результаты исследования структуры диска, текста и графики.
- `tools/` — инструменты извлечения, сборки и проверки.
- `translation/` — переводы и словари.
- `assets/` — подготовленные ресурсы русификации.
- `build/` и `release/` — локальные результаты и пакеты; исключены из Git.

Образы игры и звуковые дорожки не публикуются. Для будущего патча необходимо зафиксировать контрольные суммы собственного исходного набора, расположение файлов и дорожек. Данные проекта Mega Drive не считаются совместимыми с дисковой версией без отдельной проверки.
